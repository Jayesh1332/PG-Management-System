# PG-Management-System
A full-stack PG/Hostel Management System built using Java, Spring Boot, React, PostgreSQL, JWT Authentication, Docker and Jenkins.

## Features
- Tenant Management
- Room Management
- Rent Management
- Payment Tracking
- Admin Dashboard
- Reports

## Tech Stack
- Java 21
- Spring Boot
- PostgreSQL
- Hibernate/JPA
- Maven
- React (Frontend)
- Docker
